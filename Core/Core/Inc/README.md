# Core Header Files

## Overview

This directory contains the header files required for the core firmware development of the RFID-Based Billing System using the STM32F401RBT6 microcontroller.

## File Structure

| Header File | Description |
|---|---|
| `stm32f401rbt6.h` | Defines STM32F401RBT6 register mappings and peripheral-related definitions. |
| `gpio.h` | Provides function declarations and definitions required for GPIO configuration and control. |
| `SPI.h` | Provides function declarations for SPI peripheral communication. |
| `systicktimer.h` | Provides function declarations for SysTick timer operations. |

## Purpose

The header files define the interfaces, register declarations, and supporting definitions used by the corresponding source files. They promote modularity, code reusability, and maintainability across the firmware.
