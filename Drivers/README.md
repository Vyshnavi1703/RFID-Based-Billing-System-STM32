# Peripheral Drivers

## Overview

This directory contains the peripheral driver modules developed for the RFID-Based Billing System using the STM32F401RBT6 microcontroller.

## Driver Modules

| Driver | Description |
|---|---|
| RFID | Provides the interface for RC522 RFID reader communication through SPI. |
| LCD | Provides the interface for displaying system and billing information on a 16×2 character LCD. |

## Purpose

The driver modules separate peripheral-specific functionality from the main application code, promoting modularity, code reusability, and maintainability.
