# LCD Driver

## Overview

This directory contains the LCD driver implementation developed for interfacing a 16×2 character LCD with the STM32F401RBT6 microcontroller in the RFID-Based Billing System.

## Driver Description

The LCD driver provides the software interface required for displaying system information through the 16×2 character LCD.

## Key Responsibilities

- LCD initialization and configuration.
- Character and string display operations.
- Displaying billing-related information.
- Providing an interface between the application firmware and the LCD module.

## Directory Contents

This directory contains the LCD driver source and header files required for LCD interfacing.

## Purpose

The LCD driver separates display-related functionality from the main application logic, supporting modular firmware development, code reusability, and maintainability.
