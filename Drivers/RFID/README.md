# RFID Reader Driver

## Overview

This directory contains the RFID reader driver developed for interfacing the RC522 RFID module with the STM32F401RBT6 microcontroller in the RFID-Based Billing System.

## Driver Description

The RFID driver provides the software interface required for communication between the microcontroller and the RC522 RFID reader through the SPI communication interface.

## Key Responsibilities

- RC522 RFID module interfacing.
- SPI-based communication with the RFID reader.
- RFID card detection and data reading.
- Providing RFID-related functionality to the main application.

## Directory Contents

This directory contains the RFID driver source and header files required for RC522 module interfacing.

## Purpose

The RFID driver encapsulates RFID reader communication functionality into a separate software module, improving firmware modularity, code organisation, and maintainability.
